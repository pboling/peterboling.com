Kettle NDJSON gives command-line tools a common newline-delimited JSON event format. Helpers describe phases, steps, diagnostics, timings, and summaries, while filters control which event types appear. It is useful when another tool needs to consume progress and results without parsing terminal prose.

Read the [upstream README](https://github.com/kettle-dev/kettle-ndjson/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/kettle-dev/kettle-ndjson).
