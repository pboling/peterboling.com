Version 0.1.4 generates ActiveRecord support Gemfiles with the appropriate SQLite dependency family. It also preserves comments and unrelated settings when updating configuration. This lets generated matrices include framework setup dependencies without rewriting the rest of the project's configuration.

Read the [upstream release notes](https://github.com/appraisal-rb/kettle-jem-appraisals/releases/tag/v0.1.4) for the complete changes and see the [project repository](https://github.com/appraisal-rb/kettle-jem-appraisals) for usage and installation.
