Kettle Jem Appraisals generates dependency-test matrices for Ruby gems. It reads gemspec requirements and published dependency metadata to locate changes in supported Ruby versions, then produces modular Gemfiles, Appraisal2 definitions, and CI matrix fragments. This automates a repetitive part of compatibility testing.

Read the [upstream README](https://github.com/appraisal-rb/kettle-jem-appraisals/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/appraisal-rb/kettle-jem-appraisals).
