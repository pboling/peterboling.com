OmniAuth LDAP connects an application’s OmniAuth flow to an LDAP directory. Configure the server, search base, user lookup, and mappings for returned identity fields. Its README also documents connection timeouts, TLS configuration, and the explicit trust settings required for header-based SSO.

Read the [upstream README](https://github.com/omniauth/omniauth-ldap/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/omniauth/omniauth-ldap).
