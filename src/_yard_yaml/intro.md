YARD YAML adds YAML documents to generated YARD documentation. Enable the plugin with `--plugin yaml` in `.yardopts`; converted pages are written beneath `docs/yaml/`. The README illustrates this with a project’s `CITATION.cff`, allowing structured project metadata to appear alongside API documentation.

Read the [upstream README](https://github.com/galtzo-floss/yard-yaml/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/yard-yaml).
