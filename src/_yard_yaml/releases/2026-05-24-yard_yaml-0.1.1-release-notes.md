Version 0.1.1 preserves valid UTF-8 and handles malformed UTF-8 in non-strict mode. Binary-like input is rejected without exposing raw encoding crashes, making document conversion failures easier to handle.

Read the [upstream release notes](https://github.com/galtzo-floss/yard-yaml/releases/tag/v0.1.1) for the complete changes and see the [project repository](https://github.com/galtzo-floss/yard-yaml) for usage and installation.
