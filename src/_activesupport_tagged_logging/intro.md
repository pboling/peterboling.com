Tagged logs attach useful context to messages without repeating it at every call site. This gem backports Rails 8 ActiveSupport tagged logging, including tag stacks and formatter integration, to older supported Rails applications. Its README explains how to load and configure the accompanying logger backports.

Read the [upstream README](https://github.com/galtzo-floss/activesupport-tagged_logging/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/activesupport-tagged_logging).
