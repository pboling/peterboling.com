Appraisal2 tests a Ruby library against different dependency combinations. Named appraisals produce separate Gemfiles, making compatibility checks repeatable without replacing the normal development bundle. It also supports lifecycle hooks and separate generation, installation, and update workflows, so CI can use Gemfiles that have already been generated.

Read the [upstream README](https://github.com/appraisal-rb/appraisal2/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/appraisal-rb/appraisal2).
