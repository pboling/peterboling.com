Version 3.1.1 adds a plugin declaration to the Appraisals DSL. Companion gems can run during Gemfile generation without being copied into the generated dependency scenarios. This keeps generator tooling separate from the dependencies a compatibility test is meant to exercise.

Read the [upstream release notes](https://github.com/appraisal-rb/appraisal2/releases/tag/v3.1.1) for the complete changes and see the [project repository](https://github.com/appraisal-rb/appraisal2) for usage and installation.
