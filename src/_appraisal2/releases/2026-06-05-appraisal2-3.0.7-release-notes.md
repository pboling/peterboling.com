Version 3.0.7 fixes appraisal installation so BUNDLED WITH selects and installs the locked Bundler version instead of rewriting the lockfile with the parent process's version. This preserves the dependency scenario the appraisal was intended to reproduce.

Read the [upstream release notes](https://github.com/appraisal-rb/appraisal2/releases/tag/v3.0.7) for the complete changes and see the [project repository](https://github.com/appraisal-rb/appraisal2) for usage and installation.
