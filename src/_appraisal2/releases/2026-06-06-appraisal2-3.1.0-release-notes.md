Version 3.1.0 introduces lifecycle hooks, including an in-memory Gemfile transform, and separate generate-install and generate-update commands. Install and update now operate on existing generated Gemfiles. Review CI commands if they previously relied on installation implicitly regenerating those files.

Read the [upstream release notes](https://github.com/appraisal-rb/appraisal2/releases/tag/v3.1.0) for the complete changes and see the [project repository](https://github.com/appraisal-rb/appraisal2) for usage and installation.
