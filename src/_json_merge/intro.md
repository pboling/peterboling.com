Json::Merge handles JSON, JSONC, and JSON5 through one Ruby API. It compares parsed structure and exposes dialect-specific parsing through the shared backend registry. For commented or relaxed syntax, select the appropriate dialect rather than assuming that every JSON-like input follows the same grammar.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/json-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
