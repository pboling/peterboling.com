RuboCop LTS coordinates linting configuration for projects that support older Ruby versions. Its family of version-specific packages helps keep style tooling aligned with the project’s compatibility floor. Start with the documentation linked from the README to select the appropriate profile and plan Ruby upgrades.

Read the [upstream README](https://github.com/rubocop-lts/rubocop-lts/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/rubocop-lts/rubocop-lts).
