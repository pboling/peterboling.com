RuboCop LTS Ruby checks calls to catalogued Ruby core and standard-library methods against a configured Ruby target. It helps identify accidental use of APIs newer than a project’s supported floor. Add its plugin to the linting workflow and configure the target version as documented upstream.

Read the [upstream README](https://github.com/rubocop-lts/rubocop-lts-ruby/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/rubocop-lts/rubocop-lts-ruby).
