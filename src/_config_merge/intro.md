Config::Merge performs three-way merges of line-oriented configuration under declared policies. Policies identify flags, repeated arguments, and singleton conflicts; named normalizers are selected from validated YAML. This lets a caller combine independent option changes while surfacing conflicts that require a decision.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/config-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
