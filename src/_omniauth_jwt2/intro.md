OmniAuth JWT2 accepts signed JWT callbacks from a trusted application and maps selected claims into the OmniAuth authentication hash. The package is named `omniauth-jwt2`, while its documented Ruby entry point remains `require "omniauth/jwt"`. Configure the trust relationship and claim mapping using the strategy’s README.

Read the [upstream README](https://github.com/omniauth/omniauth-jwt2/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/omniauth/omniauth-jwt2).
