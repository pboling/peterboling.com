Rust::Merge provides Ruby tooling with structural merging for Rust source. It identifies top-level items through the shared language-pack backend, retaining destination items and adding missing template items by their structural paths. The API returns diagnostics when the parser or requested dialect is unavailable.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/rust-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
