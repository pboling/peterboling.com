RuntimeGroups supplies shared primitives for parallel test runners: worker counts, a process ledger, runtime logs, and balanced file groups. It was extracted from Turbo Tests2. Runtime-weighted grouping and deterministic tie breaking help runners distribute work repeatably across their workers.

Read the [upstream README](https://github.com/galtzo-floss/runtime_groups/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/runtime_groups).
