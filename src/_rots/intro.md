ROTS is an OpenID 2.0 provider for integration tests. Its controlled identity and server endpoints let a client test discovery, authentication, and extensions without relying on an external provider. Responses follow test configuration and request parameters, making it suitable for reproducible test scenarios.

Read the [upstream README](https://github.com/ruby-openid/rots/blob/master/README.md) for installation and usage, or browse the [project repository](https://github.com/ruby-openid/rots).
