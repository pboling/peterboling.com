The `os` gem makes operating-system and runtime information available through a Ruby API. Helpers identify Windows, macOS, JRuby, CPU details, the null device, and process memory usage. `OS.report` collects platform details into a report, useful when diagnosing behavior that differs between development and deployment machines.

Read the [upstream README](https://github.com/rdp/os/blob/master/README.md) for installation and usage, or browse the [project repository](https://github.com/rdp/os).
