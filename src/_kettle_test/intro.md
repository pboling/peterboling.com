Kettle::Test provides a shared RSpec harness for Ruby projects. Its entry point is `require "kettle/test/rspec"` in the spec helper, before loading the library under test. The README documents the supplied testing tools and configuration, including handling development bundles for older Ruby versions.

Read the [upstream README](https://github.com/kettle-dev/kettle-test/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/kettle-dev/kettle-test).
