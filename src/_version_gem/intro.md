VersionGem adds introspection to a Ruby library’s version module while retaining the normal version string used by its gemspec. Callers can inspect major, minor, patch, and prerelease values or obtain array and hash representations. It has no runtime dependencies.

Read the [upstream README](https://github.com/ruby-oauth/version_gem/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/ruby-oauth/version_gem).
