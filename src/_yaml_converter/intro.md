YAML Converter turns annotated YAML into documentation. It can render notes, validation information, and fenced YAML as Markdown, HTML, or PDF, with additional formats available through Pandoc. This is useful when a design blueprint lives in YAML but its readers need a document.

Read the [upstream README](https://github.com/galtzo-floss/yaml-converter/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/yaml-converter).
