Ast::Crispr makes targeted edits through parsed document structure. Selectors identify owners, then operations replace or delete their source ranges through a shared request and report model. Format adapters provide the syntax-specific knowledge, making it possible to edit generated regions without matching arbitrary line patterns.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/ast-crispr/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
