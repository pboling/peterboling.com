RBS Merge combines Ruby signature files through the official RBS parser. It matches declarations and can merge nested class and module bodies while retaining associated comments. Protected regions and configurable conflict preferences give callers control over template updates to their type signatures.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/rbs-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
