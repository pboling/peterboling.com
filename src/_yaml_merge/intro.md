Yaml::Merge owns the shared YAML behavior in StructuredMerge Ruby. It matches mapping entries by path and provides the source-preserving foundation used by parser-specific providers. Use TreeHaver for parser selection and Ast::Crispr for targeted edits, as described in the README.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/yaml-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
