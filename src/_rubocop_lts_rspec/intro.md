RuboCop LTS RSpec packages RSpec lint configuration for the RuboCop LTS toolchain. Select its profile with `inherit_gem`, pointing to `rspec.yml`. The gem supplies configuration rather than application runtime behavior, so its integration belongs in the linting setup.

Read the [upstream README](https://github.com/rubocop-lts/rubocop-lts-rspec/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/rubocop-lts/rubocop-lts-rspec).
