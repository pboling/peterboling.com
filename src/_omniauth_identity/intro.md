OmniAuth Identity brings username-and-password authentication into the OmniAuth request and callback flow. It provides basic user-management building blocks while leaving application policy to the host application. It is useful when local accounts need to coexist with other OmniAuth strategies.

Read the [upstream README](https://github.com/omniauth/omniauth-identity/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/omniauth/omniauth-identity).
