Citrus TOML Merge connects the Citrus parser to the shared TOML merge family. It supplies parser registration and backend-specific behavior while leaving format-level merge rules in `toml-merge`. Use the provider README to check configuration and runtime compatibility for this backend.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/citrus-toml-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
