YARD Timekeeper removes generated footer churn from checked-in YARD HTML. It restores tracked files only when their changes are limited to generated timestamps or Ruby and YARD version metadata, keeping real documentation edits intact. Its supported integration runs through `rake yard`.

Read the [upstream README](https://github.com/galtzo-floss/yard-timekeeper/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/yard-timekeeper).
