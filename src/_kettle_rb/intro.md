Kettle::Rb holds shared compatibility information for the Kettle toolchain. Its matrix records Ruby engines, dependency policies, and lint and appraisal choices; a separate platform-support API records evidenced operating-system support. Unknown engine/platform pairs remain unsupported rather than turning missing data into a claim.

Read the [upstream README](https://github.com/kettle-dev/kettle-rb/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/kettle-dev/kettle-rb).
