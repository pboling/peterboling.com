Markly Merge uses Markly’s libcmark-gfm parser with the shared Markdown merge engine. It supplies Markly-specific defaults, parser flags, and extension options while matching document sections structurally. Its default configuration enables merging inside code blocks; the README describes controls for that behavior.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/markly-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
