`@structuredmerge/typescript-compiler-merge` provides a provider that connects the TypeScript compiler to the TypeScript format layer in the StructuredMerge TypeScript family. It is one component of a layered toolkit for building merge-aware applications.

The family README documents its place in the stack. It also notes that the TypeScript implementation still trails Ruby in behavior and fixes, so check the relevant fixtures and backend support for your intended operation.

See the [package-family guide](https://github.com/structuredmerge/structuredmerge-typescript/blob/main/README.md).

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-typescript/blob/main/packages/typescript-compiler-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-typescript).
