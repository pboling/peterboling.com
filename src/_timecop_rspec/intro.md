Timecop RSpec integrates Timecop with RSpec examples and groups. Tests can run with controlled time at the example, context, or whole-suite level. The README explains the metadata and configuration needed to keep time-dependent behavior repeatable.

Read the [upstream README](https://github.com/galtzo-floss/timecop-rspec/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/timecop-rspec).
