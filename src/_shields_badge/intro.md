Shields::Badge provides Ruby badge classes through a registry and plugins. Requiring `shields/badge` enables lazy loading, while `Shields::Badge.register_all` loads the built-in set eagerly. Badge calls can return Markdown or an image source URL, making the same badge definition usable in different documentation outputs.

Read the [upstream README](https://github.com/galtzo-floss/shields-badge/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/shields-badge).
