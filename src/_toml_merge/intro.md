TOML Merge matches TOML keys and tables using parsed structure. It supports configurable conflict preferences and protected regions, and accounts for tables, dotted keys, and other TOML constructs. Follow its README for parser backend setup before wiring it into a configuration-update workflow.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/toml-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
