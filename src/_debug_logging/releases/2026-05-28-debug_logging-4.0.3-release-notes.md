Version 4.0.3 restores colorize as a runtime dependency. A fresh installation now includes the library that DebugLogging uses for colored output, rather than relying on another dependency to bring it in.

Read the [upstream release notes](https://github.com/galtzo-floss/debug_logging/releases/tag/v4.0.3) for the complete changes and see the [project repository](https://github.com/galtzo-floss/debug_logging) for usage and installation.
