DebugLogging decorates Ruby methods with configurable logging and optional timing information. Settings can be inherited and overridden by classes, instances, or methods, allowing detailed tracing in a selected part of an application. The README covers argument formatting, invocation identifiers, notifications, and logger initialization.

See the [upstream README](https://github.com/galtzo-floss/debug_logging/blob/main/README.md) and [project repository](https://github.com/galtzo-floss/debug_logging).
