FLOSS Funding lets Ruby library maintainers add funding reminders to their projects. Its integration uses `FlossFunding::Poke`, with setup guidance and an installation task in the README. Reminders run without network requests or tracking, and the documentation puts ways to silence them alongside the setup instructions.

Read the [upstream README](https://github.com/floss-funding/floss_funding/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/floss-funding/floss_funding).
