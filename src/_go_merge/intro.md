Go::Merge analyzes Go imports and top-level declarations from Ruby. Its merge behavior preserves destination declarations and adds template-only declarations in source order. Backend capability information and structured diagnostics let a host tool determine whether it can process a particular input.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/go-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
