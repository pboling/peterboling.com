Version 0.1.0 introduces a scaffold API for creating, building, installing, and cleaning up tiny fixture gems. Tests of gem tooling can use isolated fixtures instead of maintaining a full application template.

Read the [upstream release notes](https://github.com/appraisal-rb/gem_mine/releases/tag/v0.1.0) for the complete changes and see the [project repository](https://github.com/appraisal-rb/gem_mine) for usage and installation.
