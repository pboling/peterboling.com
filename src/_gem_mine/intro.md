GemMine creates small temporary Ruby gems for integration tests. Fixtures can be built, installed into an isolated gem home, or initialized as local Git repositories. The library also manages teardown, keeping tests of Bundler and RubyGems behavior from leaving temporary project directories behind.

Read the [upstream README](https://github.com/appraisal-rb/gem_mine/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/appraisal-rb/gem_mine).
