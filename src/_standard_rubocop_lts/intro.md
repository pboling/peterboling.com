Standard RuboCop LTS extends Standard Ruby configuration for projects spanning Ruby versions, including older compatibility targets. It belongs to the RuboCop LTS family and adds configuration beyond Standard’s baseline rules. Choose the profile for the oldest Ruby your project intends to support.

Read the [upstream README](https://github.com/rubocop-lts/standard-rubocop-lts/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/rubocop-lts/standard-rubocop-lts).
