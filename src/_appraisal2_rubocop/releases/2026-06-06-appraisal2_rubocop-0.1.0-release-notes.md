Version 0.1.0 connects RuboCop to Appraisal2's in-memory Gemfile transformation hook. Generated appraisal files can be formatted before they are written, keeping style maintenance in the generation workflow.

Read the [upstream release notes](https://github.com/appraisal-rb/appraisal2-rubocop/releases/tag/v0.1.0) for the complete changes and see the [project repository](https://github.com/appraisal-rb/appraisal2-rubocop) for usage and installation.
