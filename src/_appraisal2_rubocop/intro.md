Appraisal2 RuboCop formats generated appraisal Gemfiles through Appraisal2 lifecycle hooks. It belongs in the generator bundle, where a modern RuboCop toolchain is available. The README distinguishes that environment from the older runtimes a library may test through its appraisals.

Read the [upstream README](https://github.com/appraisal-rb/appraisal2-rubocop/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/appraisal-rb/appraisal2-rubocop).
