Ast Crispr Ruby Prism connects Prism-backed Ruby structure to Ast::Crispr edits. Its selectors identify requires, constants, declarations, and methods so an operation can replace the relevant source range while retaining unrelated content. Use it when a template tool needs a focused Ruby edit.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/ast-crispr-ruby-prism/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
