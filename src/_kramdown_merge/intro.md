Kramdown Merge connects Kramdown to the Markdown merge family. The adapter registers its parser and exposes capability information, common parse and merge methods, and structured failure diagnostics. It is a backend choice for callers already using the shared Markdown merge contracts.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/kramdown-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
