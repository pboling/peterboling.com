OAuth2 MCP helps Ruby HTTP MCP servers validate bearer authorization for their own resource. It provides discovery metadata, bearer challenges, scope-to-capability mapping, and provider adapters. The README emphasizes audience validation and separate downstream credentials instead of forwarding an incoming token to another service.

Read the [upstream README](https://github.com/ruby-oauth/oauth2-mcp/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/ruby-oauth/oauth2-mcp).
