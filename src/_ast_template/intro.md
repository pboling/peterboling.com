Ast::Template applies StructuredMerge templates to package directories. It plans file updates and runs sessions with dry-run and apply modes, while reporting whether repeated application converges. Higher-level tools supply package facts, letting callers update a project without assembling every merge primitive themselves.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/ast-template/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
