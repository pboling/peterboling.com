`yaml-merge` provides the shared YAML format layer used by concrete parser providers in the StructuredMerge Rust family. It is one component of a layered toolkit for building merge-aware applications.

The family README documents its place in the stack. It also notes that the Rust implementation still trails Ruby in behavior and fixes, so check the relevant fixtures and backend support for your intended operation.

See the [package-family guide](https://github.com/structuredmerge/structuredmerge/blob/main/README.md).

Read the [upstream README](https://github.com/structuredmerge/structuredmerge/blob/main/crates/yaml-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-rust).
