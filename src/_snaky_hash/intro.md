SnakyHash normalizes string and symbol hash keys into snake case and provides convenient access to the resulting values. A host hash class chooses string or symbol storage when including `SnakyHash::Snake`; optional serialization helpers are configured there too. Other key types retain their separate identity.

Read the [upstream README](https://github.com/ruby-oauth/snaky_hash/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/ruby-oauth/snaky_hash).
