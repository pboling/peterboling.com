Alef generates language bindings and package scaffolding from a Rust API and `alef.toml`. Its outputs include host-language types, documentation, tests, and release metadata. It supports multi-crate workspaces, letting maintainers coordinate several language packages from a shared source configuration.

Read the [upstream README](https://github.com/xberg-io/alef/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/xberg-io/alef).
