Version 3.5.0 adds pluck and a class-level update! operation, and corrects persisted-state reporting for deleted models. These additions let callers retrieve selected values without loading full models and distinguish objects that no longer exist in storage.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
