Version 1.3.0 supports BatchGet requests exceeding 100 items and fixes associations whose tables use primary keys other than id. Those changes address two cases where application data structures exceed the simplest model setup.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
