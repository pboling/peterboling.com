Version 3.1.0 adds increment/decrement operations and access to values before type casting. It also changes chained count queries so counting no longer loads every document into memory, which matters for large result sets.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
