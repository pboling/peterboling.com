Version 3.13.0 adds a class-level delete operation and a bang form of update_attribute. It also corrects destroyed-state reporting after a failed deletion and primary-key validation in transactions, making failure handling more reliable for callers.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/releases/tag/v3.13.0) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
