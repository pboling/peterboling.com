Version 3.13.1 fixes detection of changes to map fields. This is a persistence correctness fix: code that relies on dirty tracking needs map edits to be recognized before deciding what to write.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/releases/tag/v3.13.1) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
