Version 3.2.0 introduces find_by_pages, exposing DynamoDB query pagination to callers. It also adds a map field type. Page-aware processing can now operate through the model API instead of assembling its own lower-level query loop.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
