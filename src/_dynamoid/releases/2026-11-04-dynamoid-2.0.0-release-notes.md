Version 2.0.0 makes collection queries consistently lazy and makes missing records raise RecordNotFound. Callers that expected an Array or a nil result need explicit conversion or error handling. The release also introduces Document.import and association fixes.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
