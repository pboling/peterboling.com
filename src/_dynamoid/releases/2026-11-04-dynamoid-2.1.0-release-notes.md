Version 2.1.0 adds set-element typing, ISO-formatted date storage options, and lower-level update and upsert methods. These features give applications more control over how values are stored and how targeted writes are issued.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
