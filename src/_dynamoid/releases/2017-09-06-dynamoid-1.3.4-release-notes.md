Version 1.3.4 extends query support for secondary indexes and batch loading. It also fixes default-value application and the conversion of empty arrays to nil, making stored values better match the values supplied by the application.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
