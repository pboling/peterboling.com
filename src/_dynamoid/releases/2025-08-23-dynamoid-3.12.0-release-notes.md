Version 3.12.0 fixes persistence of custom types and conversion of partition keys into DynamoDB-compatible values. Transactional writes with non-native key types are also corrected. The affected paths are worth exercising with the application's actual serializers and key classes before upgrading.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
