Version 3.0.0 changes stored booleans to native DynamoDB booleans by default and changes timezone defaults to UTC. Finder type casting and the AWS SDK migration also change behavior. Review existing data representations and timezone assumptions before crossing this major-version boundary.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
