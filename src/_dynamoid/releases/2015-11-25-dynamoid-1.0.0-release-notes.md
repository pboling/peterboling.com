Version 1.0.0 moves to AWS SDK v2 and adds custom-class field types. It also removes Dynamoid's earlier partitioning and pseudo-index features, so the release requires checking both adapter integration and model declarations before upgrading.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
