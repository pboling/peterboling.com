Version 3.14.0 corrects lock-version handling and several transactional key paths. In particular, explicitly supplied lock versions are preserved, nil lock versions can disable locking, and transactional save/update operations support reserved words in key names. Applications relying on those cases should include them in upgrade regression checks.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/releases/tag/v3.14.0) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
