Version 3.3.0 adds field projection and NULL/NOT_NULL query operators. It also fixes thread safety during adapter loading. The new query controls reduce the need to fetch every attribute when only a subset is needed.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
