Version 3.4.0 adds TTL configuration through the expires table option, along with table-level timestamp controls and on-demand capacity configuration. Applications can describe more of their DynamoDB table behavior alongside the model declaration.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
