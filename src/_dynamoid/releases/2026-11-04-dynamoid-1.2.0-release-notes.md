Version 1.2.0 introduces secondary-index support and synchronous table creation, alongside association and query fixes. Waiting for table creation is particularly relevant when a newly created table must be ready before the next operation runs.

Read the [upstream release notes](https://github.com/Dynamoid/dynamoid/blob/master/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/dynamoid/dynamoid) for usage and installation.
