Archivist Client searches Internet Archive book records and downloads matching items. The README demonstrates creating a client, searching a publication-year range, and iterating through the books to download them. It provides a Ruby entry point for that archive workflow.

See the [upstream README](https://github.com/wordtreefoundation/archivist-client/blob/master/README.md) and [project repository](https://github.com/wordtreefoundation/archivist-client).
