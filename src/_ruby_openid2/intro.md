Ruby OpenID2 implements the client and server sides of OpenID 1.x/2.0. It includes discovery, association handling, stores, and extension support. Use the protocol APIs directly for custom integrations, or start with `rack-openid2` and `open_id_authentication` for Rack and Rails applications.

Read the [upstream README](https://github.com/ruby-openid/ruby-openid2/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/ruby-openid/ruby-openid).
