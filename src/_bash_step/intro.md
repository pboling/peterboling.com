Bash Step is a shell function library that depends on Peter Boling’s fork of BSFL. The upstream README points to that dependency as the starting point for using the project. It is a small building block for shell scripts; the README does not document a larger command-line interface.

Read the [upstream README](https://github.com/pboling/bash_step/blob/master/README.md) for installation and usage, or browse the [project repository](https://github.com/pboling/bash_step).
