The `ruby-openid` repository now documents the `ruby-openid2` implementation. It supplies client and server protocol APIs, discovery, association storage, and OpenID extensions. For a maintained integration, consult that README and the Rack or Rails adapters it recommends; the protocol here is legacy OpenID.

Read the [upstream README](https://github.com/ruby-openid/ruby-openid2/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/ruby-openid/ruby-openid).
