Smorg RB is the command layer for Ruby-based StructuredMerge workflows. It turns file arguments and merge-driver inputs into requests for the appropriate format library and reports structured diagnostics. The README shows invoking the runtime from Ruby as well as configuring the surrounding merge gems.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/smorg-rb/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
