Version 3.2.14 fixes root-aggregated spec paths when member gems also contain .rspec files. The preceding release could reduce those paths to nonexistent root-relative files and abort parallel grouping before tests ran.

Read the [upstream release notes](https://github.com/galtzo-floss/turbo_tests2/releases/tag/v3.2.14) for the complete changes and see the [project repository](https://github.com/galtzo-floss/turbo_tests2) for usage and installation.
