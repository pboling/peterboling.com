Version 3.2.9 makes early worker failures visible as errors outside examples. It also uses JSON.generate for result rows, avoiding a crash caused by incompatible ActiveSupport to_json overrides.

Read the [upstream release notes](https://github.com/galtzo-floss/turbo_tests2/releases/tag/v3.2.9) for the complete changes and see the [project repository](https://github.com/galtzo-floss/turbo_tests2) for usage and installation.
