Version 3.2.7 adds --no-rake-hooks. Callers can run the parallel test suite without discovering a Rakefile or invoking its setup and cleanup hooks.

Read the [upstream release notes](https://github.com/galtzo-floss/turbo_tests2/releases/tag/v3.2.7) for the complete changes and see the [project repository](https://github.com/galtzo-floss/turbo_tests2) for usage and installation.
