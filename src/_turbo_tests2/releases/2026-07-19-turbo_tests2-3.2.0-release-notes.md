Version 3.2.0 adds explicit worker-output modes: warnings, streaming, buffering, and quiet output. Teams can choose how subprocess output reaches the terminal instead of accepting one presentation policy for every run.

Read the [upstream release notes](https://github.com/galtzo-floss/turbo_tests2/releases/tag/v3.2.0) for the complete changes and see the [project repository](https://github.com/galtzo-floss/turbo_tests2) for usage and installation.
