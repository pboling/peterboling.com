Version 3.1.9 prevents invalid UTF-8 in worker output from crashing the parent runner on JRuby. Passing examples can now complete without a reporting failure caused by those bytes.

Read the [upstream release notes](https://github.com/galtzo-floss/turbo_tests2/releases/tag/v3.1.9) for the complete changes and see the [project repository](https://github.com/galtzo-floss/turbo_tests2) for usage and installation.
