`tree-sitter-language-pack` brings tree-sitter-language-pack to Python projects. The upstream project packages parsers for hundreds of languages behind a shared API, with syntax-tree traversal and code-intelligence operations.

The root README links to the language-specific installation and quick-start material. Check that binding’s documentation for deployment details, particularly parser downloads and the distinction between native and WebAssembly packages.

Read the [upstream README](https://github.com/xberg-io/tree-sitter-language-pack/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/xberg-io/tree-sitter-language-pack).
