Kettle::Jem updates Ruby gem projects from shared templates using syntax-aware merges. Per-file strategies, token replacement, and protected regions control how template changes interact with local customization. It builds on StructuredMerge’s format libraries and documents a plugin interface for extending the workflow.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/kettle-jem/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
