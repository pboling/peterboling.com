This RuboCop LTS profile selects lint configuration for projects whose oldest supported Ruby is 1.9. It brings together the relevant RuboCop, Standard, Betterlint, and Gradual settings. Use the README’s integration instructions to keep linting choices aligned with the project’s compatibility target.

Read the [upstream README](https://github.com/rubocop-lts/rubocop-ruby1_9/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/rubocop-lts/rubocop-ruby1_9).
