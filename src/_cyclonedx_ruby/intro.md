CycloneDX Ruby generates a software bill of materials from a Ruby project’s dependencies. The CLI supports XML and JSON output and lets callers select the CycloneDX specification version. Point it at a project directory and choose an output path to incorporate dependency inventory into a release workflow.

Read the [upstream README](https://github.com/CycloneDX/cyclonedx-ruby-gem/blob/master/README.md) for installation and usage, or browse the [project repository](https://github.com/cyclonedx/cyclonedx-ruby-gem).
