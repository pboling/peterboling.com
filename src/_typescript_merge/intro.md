TypeScript::Merge brings structural TypeScript updates to Ruby tools. It matches declarations through the shared parser backend and keeps destination declarations while adding missing template content. Its README documents module-level methods and capability reporting for host integrations.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/typescript-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
