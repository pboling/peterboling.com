Binary::Merge supplies planning and reporting primitives for schema-aware binary formats. It records byte ownership, preservation decisions, and unsafe edits for concrete format libraries such as `zip-merge`. It does not assume that an arbitrary binary file can be merged safely.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/binary-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
