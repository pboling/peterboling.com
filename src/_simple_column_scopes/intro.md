Simple Column Scopes generates named query methods from a list of model columns. It gives repeated queries a consistent vocabulary that is easy to search for in an application. Invalid column names or scope prefixes raise errors, helping make mistakes visible at the call site.

Read the [upstream README](https://github.com/galtzo-floss/simple_column-scopes/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/simple_column-scopes).
