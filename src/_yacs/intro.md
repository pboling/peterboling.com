YACS is a React single-page application for viewing and managing live token data. The current README describes filtering, sorting, and WebSocket updates, with a Rolldown-Vite-based frontend. Browse its setup instructions to run the application and explore the real-time interface.

See the [upstream README](https://github.com/pboling/yacs/blob/main/README.md) and [project repository](https://github.com/pboling/yacs).
