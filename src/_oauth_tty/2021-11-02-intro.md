OAuth::TTY provides command-line access to the Ruby OAuth 1.0/1.0a tooling. It is a companion to the `oauth` library for working with that protocol from a terminal. Follow its README for installation and command usage; OAuth 2 integrations use the separate `oauth2` library.

Read the [upstream README](https://github.com/ruby-oauth/oauth-tty/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/ruby-oauth/oauth-tty).
