Kettle Changelog prepares versioned changelog sections from unreleased notes. It updates comparison links, can include coverage and documentation statistics, and emits structured events for orchestration. Environment variables select alternate changelog and coverage paths when release tooling operates outside a simple single-gem layout.

Read the [upstream README](https://github.com/kettle-dev/kettle-changelog/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/kettle-dev/kettle-changelog).
