Ruby::Merge combines Ruby files by declarations and other source entities. It can retain destination method bodies while adding template-only requires, constants, classes, or methods according to configuration. The README exposes module-level APIs and diagnostic controls for callers building update or Git workflows.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/ruby-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
