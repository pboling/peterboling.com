Kettle::Dev supplies development and release tooling for Ruby gems. Requiring `kettle/dev` from a Rakefile installs tasks, while its command-line tools handle changelogs, releases, Git remotes, and commit hooks. Project scaffolding and template refreshes belong to the companion `kettle-jem` project.

Read the [upstream README](https://github.com/kettle-dev/kettle-dev/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/kettle-dev/kettle-dev).
