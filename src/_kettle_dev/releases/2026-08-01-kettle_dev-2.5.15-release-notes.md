Version 2.5.15 adds verified release-backfill checks, changelog reformatting, and update mode for existing GitHub Release notes. Maintainers gain explicit tools for reconciling historical metadata instead of treating every release operation as a new publication.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-dev/releases/tag/v2.5.15) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-dev) for usage and installation.
