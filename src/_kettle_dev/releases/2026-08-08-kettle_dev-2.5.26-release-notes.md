Version 2.5.26 applies the release lockfile environment to project-local checks, including prefixed Rake commands. This prevents local workspace paths from being reintroduced during validation and lets secret providers recognize prefixed release commands.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-dev/releases/tag/v2.5.26) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-dev) for usage and installation.
