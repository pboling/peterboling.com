Version 2.5.12 keeps existing lockfile platforms and adds the current host during a full reset. A maintainer rebuilding on another platform no longer accidentally drops Linux from the release lockfile.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-dev/releases/tag/v2.5.12) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-dev) for usage and installation.
