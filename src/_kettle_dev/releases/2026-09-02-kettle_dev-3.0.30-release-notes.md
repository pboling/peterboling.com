Version 3.0.30 adds a family-member publish mode designed for concurrent monorepo releases. It gives orchestration a dedicated isolated path for member publication rather than reusing the ordinary whole-project invocation.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-dev/releases/tag/v3.0.30) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-dev) for usage and installation.
