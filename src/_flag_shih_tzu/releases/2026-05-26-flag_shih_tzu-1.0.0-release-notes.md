Version 1.0.0 adds tri-state values and configurable bit widths and encoders, extending flags beyond true and false. Array and hash assignment also let callers update named flags without calculating packed integers themselves.

Read the [upstream release notes](https://github.com/galtzo-floss/flag_shih_tzu/releases/tag/v1.0.0) for the complete changes and see the [project repository](https://github.com/galtzo-floss/flag_shih_tzu) for usage and installation.
