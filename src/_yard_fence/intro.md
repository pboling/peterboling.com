YARD Fence prevents YARD from interpreting braces in Markdown code examples as documentation links. It prepares temporary input files, then restores ordinary braces in the generated HTML so examples remain copyable. Use its documented `rake yard` workflow, which runs the required preparation and postprocessing hooks.

Read the [upstream README](https://github.com/galtzo-floss/yard-fence/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/yard-fence).
