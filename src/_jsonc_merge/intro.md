The StructuredMerge catalog retains the `jsonc-merge` name, but current documentation places JSONC support in `json-merge`. Ruby callers use `Json::Merge` and `require "json/merge"` for JSONC as well as JSON. Start with that package’s dialect guidance when maintaining an older JSONC integration.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/json-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
