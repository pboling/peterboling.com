Ast Crispr Markdown Markly identifies Markdown sections, link definitions, and HTML comments as editable structures. Heading selectors include nested subsection content, enabling focused README updates through Ast::Crispr. Markly supplies the parser behind the adapter.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/ast-crispr-markdown-markly/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
