Capistrano Mailer sends deployment notifications using ActionMailer. Its README documents legacy Capistrano and Rails integrations, with separate branches for Rails 2 and Rails 3. It is useful as a reference for maintaining those older deployments; check the branch-specific requirements before making changes.

See the [upstream README](https://github.com/galtzo-floss/capistrano_mailer/blob/main/README.md) and [project repository](https://github.com/galtzo-floss/capistrano_mailer).
