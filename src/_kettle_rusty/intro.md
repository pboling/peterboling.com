Kettle Rusty is Rust project tooling built on the StructuredMerge kernel. It remains in the Rust native-layer repository after the kernel crates moved to a separate repository. The README describes local validation and notes that publishing depends on validating the registry-resolved kernel dependency.

See the [package-family guide](https://github.com/structuredmerge/structuredmerge-rust/blob/main/README.md).

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-rust/blob/main/crates/kettle-rusty/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-rust).
