Ast Merge Git connects StructuredMerge’s Ruby libraries to Git merge and diff workflows. It accepts ancestor, current, and incoming content and coordinates format selection and diagnostics. Repository attributes and provider settings control the integration; parser configuration remains in the relevant format gem.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/ast-merge-git/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
