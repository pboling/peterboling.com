Galtzo OS is my personal operating system: an atomic, image-based Fedora spin built on Universal Blue’s Aurora DX with Ruby, Java, 1Password, and NordVPN included. It is built as an OCI image with BlueBuild, so the whole system is declared in a repository and rebuilt, rather than configured by hand.

Browse the [project repository](https://github.com/pboling/galtzo-os).
