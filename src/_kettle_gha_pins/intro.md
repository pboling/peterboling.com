Kettle GHA Pins centralizes GitHub Actions reference resolution and upgrade planning. It shares release metadata, caching, and version-selection rules across maintenance tools. Its README also documents a CLI with check and write modes for updating workflow pins.

Read the [upstream README](https://github.com/kettle-dev/kettle-gha-pins/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/kettle-dev/kettle-gha-pins).
