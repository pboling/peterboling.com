Version 0.3.10 adds strict offline resolution, JSON inventory and cache-review modes, and configurable metadata lifetimes. Pin maintenance can inspect cached evidence without requiring a network lookup during every run.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-gha-pins/releases/tag/v0.3.10) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-gha-pins) for usage and installation.
