Version 0.2.0 introduces shared cache, GitHub-client, and reference-resolution APIs, plus a CLI that scans workflow YAML and writes immutable SHA references. Other tools can reuse the same selection and caching behavior.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-gha-pins/releases/tag/v0.2.0) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-gha-pins) for usage and installation.
