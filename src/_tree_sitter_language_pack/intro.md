Tree-sitter Language Pack provides compiled tree-sitter parsers for 300+ languages behind one dependency and with no grammars to compile. The core is a Rust library, with bindings published for other ecosystems (this family also includes the Python package), and I help maintain it.

Browse the [project repository](https://github.com/xberg-io/tree-sitter-language-pack).
