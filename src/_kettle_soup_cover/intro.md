Kettle Soup Cover centralizes SimpleCov setup and coverage policy through environment variables. It can enable branch coverage, separate parallel worker output, and collate the reports before enforcing coverage thresholds. Load it before the code under test and follow the README’s SimpleCov initialization order.

Read the [upstream README](https://github.com/kettle-dev/kettle-soup-cover/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/kettle-dev/kettle-soup-cover).
