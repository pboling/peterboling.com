StructuredMerge Go provides merge contracts and format libraries in one Go module. It includes parser adapters, AST review structures, format-specific packages, archive planning, and project-maintenance helpers. Its README explicitly treats the implementation as a consumer of shared fixtures and does not claim full behavioral equivalence with the Ruby implementation.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-go/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-go).
