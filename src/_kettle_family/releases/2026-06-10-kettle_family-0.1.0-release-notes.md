Version 0.1.0 introduces template orchestration, syntax-aware version changes, and gated release workflows. Check, dry-run, and execute modes separate inspection from mutation, while branch-lane discovery supports families released from multiple branches.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-family/releases/tag/v0.1.0) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-family) for usage and installation.
