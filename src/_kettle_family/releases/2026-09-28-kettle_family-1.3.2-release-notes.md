Version 1.3.2 improves Windows path and pipe handling in family workflows. It also closes child input when an OTP provider returns no code, preventing the interactive release process from waiting indefinitely.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-family/releases/tag/v1.3.2) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-family) for usage and installation.
