Version 1.2.0 adds clean-unreleased, which finds selected family gems installed above their latest released versions. It provides a recovery path after a failed release leaves unpublished local installations behind.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-family/releases/tag/v1.2.0) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-family) for usage and installation.
