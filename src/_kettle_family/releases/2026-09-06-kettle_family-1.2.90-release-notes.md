Version 1.2.90 adds aggregate and disposable-worktree execution modes for monorepo tests. Maintainers can select the execution model appropriate to the family rather than treating every member as an independent checkout.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-family/releases/tag/v1.2.90) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-family) for usage and installation.
