Version 1.2.21 schedules template work in dependency waves and adds version and mise-trust commands. Dependency-aware ordering lets upstream members finish before downstream template work depends on them.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-family/releases/tag/v1.2.21) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-family) for usage and installation.
