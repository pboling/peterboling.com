Version 0.1.4 adds configurable readiness checks and root/shared changelog support for monorepo releases. Release environment overrides and an optional family changelog phase help coordinate members sharing one release record.

Read the [upstream release notes](https://github.com/kettle-dev/kettle-family/releases/tag/v0.1.4) for the complete changes and see the [project repository](https://github.com/kettle-dev/kettle-family) for usage and installation.
