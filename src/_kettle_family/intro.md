Kettle Family coordinates maintenance across related Ruby gems. It discovers members, orders work, runs shared checks, and manages aligned version and release workflows. Families may span repositories or branches; resumable publishing checks for already-published versions before repeating release preparation.

Read the [upstream README](https://github.com/kettle-dev/kettle-family/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/kettle-dev/kettle-family).
