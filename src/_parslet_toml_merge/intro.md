Parslet TOML Merge provides a Parslet-backed adapter for the shared TOML merge library. It allows a caller to choose that parser while retaining the family’s common integration contracts. Follow the provider README for backend configuration and available APIs.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/parslet-toml-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
