SequentialFile helps create and select files with a consistent sequence in their names. Its naming scheme combines a leading component, a date stamp, a counter marker, and the counter itself. This gives scripts a predictable way to identify successive input or output files.

See the [upstream README](https://github.com/galtzo-floss/sequential_file/blob/main/README.md) and [project repository](https://github.com/galtzo-floss/sequential_file).
