Version 3.1.9 enables table-free models on ActiveRecord 6.0 through 8.1. Those versions previously raised Unsupported during loading, so this is a concrete compatibility expansion for applications moving beyond Rails 5.

Read the [upstream release notes](https://github.com/galtzo-floss/activerecord-tablefree/blob/main/CHANGELOG.md) for the complete changes and see the [project repository](https://github.com/galtzo-floss/activerecord-tablefree) for usage and installation.
