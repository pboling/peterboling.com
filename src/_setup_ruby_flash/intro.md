Setup Ruby Flash is a GitHub Action that uses prebuilt Ruby distributions from `rv` and installs gems with `rv clean-install`. It caches Ruby and gem installation work and documents platform-specific setup, including Windows native dependencies. Use its README to configure the action for your workflow.

Read the [upstream README](https://github.com/appraisal-rb/setup-ruby-flash/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/appraisal-rb/setup-ruby-flash).
