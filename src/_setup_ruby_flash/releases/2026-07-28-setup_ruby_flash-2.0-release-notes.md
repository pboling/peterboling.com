Version 2.0 adds main-bundle-install so appraisal workflows can omit installation of the root Gemfile. It also corrects bundle-path export and retry handling for configured sources.

Read the [upstream release notes](https://github.com/appraisal-rb/setup-ruby-flash/releases/tag/v2.0) for the complete changes and see the [project repository](https://github.com/appraisal-rb/setup-ruby-flash) for usage and installation.
