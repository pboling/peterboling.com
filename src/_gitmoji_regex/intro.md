Gitmoji::Regex supplies a Ruby regular expression for the Gitmoji emoji set. Use it to recognize a commit-message prefix or scan text for matching emoji. The README demonstrates both matching and extraction through `Gitmoji::Regex::REGEX`; it is intended for Gitmoji rather than every Unicode emoji.

Read the [upstream README](https://github.com/galtzo-floss/gitmoji-regex/blob/main/README.md) for installation and usage, or browse the [project repository](https://github.com/galtzo-floss/gitmoji-regex).
