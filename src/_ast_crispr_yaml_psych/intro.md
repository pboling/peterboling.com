Ast Crispr YAML Psych exposes YAML mapping entries and sequence items for structured editing. It connects Ast::Crispr to Psych Merge so targeted operations can retain comments and layout around the edited content. Use its selectors when a configuration update should affect a particular YAML owner.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/ast-crispr-yaml-psych/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
