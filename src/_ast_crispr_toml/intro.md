Ast Crispr TOML exposes tables and dotted key paths as editable owners. Through the common Ast::Crispr operations, a tool can update configuration such as `mise.toml` while accounting for comments and table boundaries. Parser selection stays behind the TOML merge provider interface.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/ast-crispr-toml/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
