Html::Merge adds HTML parsing and structural analysis to the Ruby StructuredMerge stack. It exposes backend profiles and diagnostics through TreeHaver, plus helpers for repairing YARD content wrappers. The README demonstrates parsing HTML and inspecting the resulting analysis.

Read the [upstream README](https://github.com/structuredmerge/structuredmerge-ruby/blob/main/gems/html-merge/README.md) for installation and usage, or browse the [project repository](https://github.com/structuredmerge/structuredmerge-ruby).
